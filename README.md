# CSCE Complete Masters

A self-contained study map of the Texas A&M CSCE graduate sequence: 50 courses, free audit links, lecture scripts, a 30-credit planner, and browser-generated notes and slide decks.

This is a study aid based on public catalog descriptions. It is not an official Texas A&M degree audit and it does not enroll you.

## Run locally

```bash
npm install
npm run dev
```

The dev server listens on port 8080.
